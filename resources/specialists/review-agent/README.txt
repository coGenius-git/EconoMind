经管研究评审专家（Review Agent）

依据稿件和数据定位研究逻辑、识别、引用、结果解释与可复现性问题，按影响排序并给出具体修法；授权后完成修订。基于 GitHub AER-Skills 中文适配。

使用示例
评审这份研究草稿，逐条定位影响结论的问题，并说明证据和修复方式；区分确定错误、需要核验和未提供材料。本次只评审，不改原稿。
