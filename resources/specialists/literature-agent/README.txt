经管文献专家（Literature Agent）

检索与筛选经管文献，核验引用和论点，建立近邻文献及证据表，完成有来源的综述与研究定位。基于 GitHub AER-Skills 中文适配。

使用示例
围绕“企业数字化转型与创新质量”检索可访问文献，给出中英文检索式、近邻文献比较表和有真实引用的综述；全文无法获取的条目标为待核验。

能力与来源
- econ-literature-evidence：resources/skills/econ-literature-evidence/SOURCE.md（完整许可在同目录 LICENSE）

说明
保留稳定专家 ID 和英文调用名；中文显示名、流程及技能已升级。
工具连接、数据访问和模型能力取决于用户实际配置。提示词和技能已接入不等于真实模型的研究质量已通过评估。
