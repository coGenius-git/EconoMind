文献查找专家（Literature Agent）

明确检索范围、查找并核验文献，交付检索日志及文献表。原 literature-agent ID 和英文调用名保留，兼容已有会话。

选择后输入框自动填入可编辑示例，包括时间、学科、语言、地区、文献类型、来源及数量范围。实际数据库覆盖与全文访问取决于已配置连接器和权限。

可复制示例：
我正在研究“企业数字化转型如何影响创新绩效”，请查找2015年至今经济学、管理学、金融学与会计学领域的中英文文献。以中国企业为主，兼顾国际研究；优先期刊论文与工作论文，不包含新闻、学位论文和一般评论。优先检索知网、Web of Science、Google Scholar及公开学术数据库，以实际可访问来源为准。筛选20篇左右，优先考虑相关性和研究质量。请记录实际检索词、日期、范围及未覆盖来源，交付题名、作者、年份、发表来源、研究问题、主要发现、相关性说明、全文可得性和来源链接。
