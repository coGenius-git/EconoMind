# 文献计量分析（Bibliometrics）

## 定位

面向经济学 / 管理学 / 金融学 / 会计学 / 公共政策研究者的文献计量辅助。
输入是文献集合（标题、年份、关键词），输出是**可复核的统计结果与图表数据**，
帮助研究者定位研究热点、聚类主题、观察时间演化——最终判断由研究者自己做出。

## 输入

- 文献列表，每条包含：`title`、`year`（可空）、`keywords`（可空，逗号/分号/竖线分隔）。
- 无显式关键词时，`keywords_from_title` 会从标题提取英文词元与中文短词。

## 计算步骤

1. **关键词频次**：统计每个关键词覆盖的文献数。
2. **共词分析**：同一文献内两两关键词的共现次数 → 共现网络（`cooccurrence_matrix`）。
3. **关键词聚类**：对共现网络取连通分量作为主题簇（`cluster_keywords`），
   每簇给出代表词与文献覆盖数。
4. **研究热点**：关键词频次 + 近 3 年（相对最新年份）增长率（`hotspots`）。
5. **时间演化**：按年份统计 Top 关键词出现次数（`topic_trends`）。

## 输出

- `bibliometrics_markdown(analysis)`：可直接落盘的 Markdown 报告，
  含关键词频次表、共现 Top 边、簇清单、热点清单、逐年趋势表。
- 结构化 JSON（`to_json(analysis)`）：供前端 ECharts 直接渲染
  知识图谱 / 关键词网络 / 研究趋势图。

## 关键约定

- **不编造数据**：所有数字都来自输入文献集合；输入为空时返回空分析并明确说明。
- **不替代研究者**：聚类与热点是描述性统计，不是"研究结论"；报告内不写评价性论断。
- **可复核**：每条共现 / 频次都可回溯到具体文献；输出不隐藏计算口径。
- 年份缺失的文献不参与时间演化与热点窗口计算，但在文献计数中保留。
- 聚类仅依赖共现连通分量，不引入任何外部依赖（纯 Python 标准库）。
