# 经管文献与证据

本技能从 AER Literature 改编，适用一般经管研究，不预设目标期刊、文献篇数或论文必有创新。来源、版本和修改说明见 [SOURCE.md](SOURCE.md)，许可见 [LICENSE](LICENSE)。

## 从现有材料开始

读取用户的研究问题、稿件和已导入文献，确定对象、情境、关键构念、结果变量、时间范围和所需产物。沿用用户已有标准；只问会实质改变检索或判断的缺口。简单查一篇文章就交付核验后的文章；综合综述才执行完整流程。用户要求综述、假设或引言草稿时，在已核实证据上完成草稿，区分文献事实与 AI 提出的综合、解释和假设。

先查看当前会话工具。连接器通过 JavaScript 控制 REPL 的 `repl_execute` 使用：先 `await host.capabilities()`，再按 `await host.help()` 的实际目录发现检索和项目文件接口。只有 `caps.mcp === true` 且已发现具体方法时才调用 `host.mcp`。文献连接器被选中不代表已配置凭据、拥有数据库订阅或能获取全文。Python/R 数据内核不能调用连接器；不要猜测 API 名称、读其他软件的凭据或用原始网络请求绕开权限。

## 1. 检索与筛选

1. 将问题拆成中英文关键词组，区分理论构念、常用代理指标和同名异义词；按可用来源实际支持的语法组合检索式。
2. 用可访问的学术元数据、期刊/工作论文记录和用户文献库检索。NBER、RePEc、SSRN、CNKI 等仅为适用时的候选来源；没有工具或访问权就记录未覆盖，不能声称已检索。已有中文材料可直接分析，不因缺少 DOI 排除。
3. 从最相关的论文追溯参考文献和后续引用，检查公开工作论文与正式发表版本。保留有实质差异的版本关系；不能用某版本正文支持另一版本的精确数值。
4. 记录每次检索的来源、日期、完整检索式、过滤条件、实际取回数量和分页/截断情况。按规范化 DOI 去重；无 DOI 时比对题名、作者与年份，模糊匹配保留待核验状态。
5. 按问题与方法适配性筛选，记录“纳入／排除／待定”和具体理由。引用量、期刊等级不是可信度或相关性的替代；正文不可得或摘要信息不足时保留待定。用户授权自动筛选时执行其标准，无需每篇重新确认。

若检索无结果，尝试有根据的关键词扩展或更换可用来源后说明覆盖范围。结论是“本次检索未发现”，不能据此断言全世界不存在研究。

## 2. 近邻文献与研究定位

对最接近问题的实际文献建立表格（数量由任务和材料决定）：

| 文献及稳定链接 | 研究问题/构念 | 情境、样本和时期 | 数据/测量 | 方法及识别假设 | 实际发现 | 未覆盖边界 | 证据定位 |
| -------------- | ------------- | ---------------- | --------- | -------------- | -------- | ---------- | -------- |

“未覆盖边界”必须来自对该文献的阅读，不贬低原研究、不把自己的猜测写成事实。对管理学材料额外区分理论机制、构念效度、问卷/案例/访谈证据和统计推断；不把所有研究强行套成政策 DID。

贡献定位可以来自新问题、测量、数据、机制、识别、情境边界或对既有结果的复核。每项定位对照近邻文献说明“已知什么、拟增加什么、还缺什么证据”；材料不足时提供候选贡献，不包装成已证实创新。若最近研究已覆盖相同问题，直接报告重合并提出具体调整方案。

## 3. 引用与论点分别核验

逐项记录以下层级，禁止把“DOI 可解析”写成“该论点已证实”：

- **书目存在性**：已取回的出版机构/DOI/正式机构记录；用户提供的可识别原文也可作为来源。无 DOI 但有可靠记录仍可引用。
- **字段与版本**：作者顺序、题名、年份、期刊或工作论文机构、稳定链接；未知卷期页码留空，不能补造。记录发现的更正/撤稿通知；未发现标记不等于证明从未更正。
- **论点支持**：对具体论点读取相关原文。摘要仅支持摘要明确表述的内容；精确效应量、机制和方法限制必须定位相应页码、节、表或图。不能把摘要推断伪装成全文精读。
- **核验状态**：分别标记“已核实／部分核实／未核实／有冲突”，保留失败原因与下一步。网络错误不等于文献不存在。

论点证据表使用：论点、文献键、正文定位/链接、实际支持范围、读取层级、核验状态、限制。引用格式可按用户要求调整，BibTeX/RIS 只填已核实字段。对用户原稿中的存疑引用标注并建议修正；未获改稿授权时保留原稿。

## 4. 综合与交付

按研究问题、机制、情境或方法综合证据，而非逐篇堆砌摘要。解释一致与冲突可能来自的样本、测量和设计差异；因果、相关、预测和理论命题分别表述。不同设计的系数不直接拼成平均效应；未做元分析不得冒称合并估计。

按任务规模交付实际内容：

- 检索/筛选任务：检索日志和筛选表，明确尚未覆盖或待定材料。
- 综述/开题任务：近邻文献表、论点证据表、带真实引用的综述或定位草稿。
- 引用审核：字段/论点核验表及具体修改建议；已授权时同时给出修订副本。

使用可用文件工具保存可编辑产物；表格/文本处理可用 `notebook_execute`。Notebook 文件保存到当前执行目录的相对路径，再用实际运行返回的 runId 发布，例如 `write_artifact_file({filename:"literature-evidence.csv",source:{kind:"localPath",path:"literature-evidence.csv"},producerRunId:"<真实runId>"})`；以工具返回的可访问链接交付。示例文件名可按任务调整，不伪造 runId 或文件链接。大任务交付 CSV/Markdown，小任务直接在回复给出结果，不为一条引用制造整套空文件。

交接时写明研究问题、已读材料、核验层级、核心发现、待解决缺口和已有产物路径，让研究设计或评审专家能继续使用。工具失败时完成可独立进行的分析，明确哪些检索或核验尚未运行。
