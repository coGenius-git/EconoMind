# 研究设计助手

## 定位

帮助经管研究者把研究问题结构化为一页可评审的研究设计：
**研究问题 → 理论视角 → 变量设计 → 假设 → 计量模型**。
产物是 `research_design.md`，作为后续文献综述、数据收集与分析的基础文档。

## 输入

- `question`：研究问题的自然语言描述（例如 "数字化转型对企业创新的影响"）。
- `explicit`（可选）：研究者已明确的变量与模型信息：
  - `x` / `y` / `mediator` / `moderator` / `controls`：自变量 / 因变量 / 中介 / 调节 / 控制变量。
  - `theory`：理论视角（如资源基础观、交易成本理论）。
  - `data`：计划数据来源与样本（如 CSMAR 上市公司面板 2015–2025）。
  - `method`：偏好方法（如面板固定效应、DID）。

## 输出

`build_design(question, explicit)` 返回结构化的研究设计框架：

- `researchQuestion`：规范化的研究问题表述。
- `theory`：理论视角（有则保留，无则列出候选并标注"待研究者确认"）。
- `variables`：`x` / `y` / `mediator` / `moderator` / `controls`。
- `hypotheses`：基于变量组合生成的假设草案（标注为草案，可修改）。
- `model`：计量模型设定（含变量代号的回归式模板，`ε` 为误差项）。
- `data`：数据来源与样本（来自 explicit 或留空待补充）。

`design_markdown(framework)` 生成 `research_design.md`。

## 关键约定

- **不编造**：变量与理论只来自输入；缺失字段保留带说明的占位，
  不默认填值。假设是"草案"，模型是"模板"，均明确标注待研究者确认。
- **不替代研究者**：本工具组织思路，不判断研究价值，也不撰写论文正文。
- **可复核**：每个输出字段都可回溯到输入。
- 中文或英文研究问题均可；输出保留输入语言。
