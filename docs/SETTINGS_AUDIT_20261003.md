## 本次发现并修复的问题

1. **文献分类请求过早超时。** 智能合集文献分类原来共享快速路由的 3 秒时限，正常但较慢的模型响应会失败。现文献分类采用 60 秒时限，技能与阅读路由继续使用原有快速回退预算。新增 5 秒成功响应及超时终止回归，相关 92 项测试通过。
2. **旧配置兼容被品牌替换破坏。** 恢复 Open Science/Open-Science 的 RIS 机构作者标记、托管 Codex 配置标记、旧数据根与 Electron 配置目录识别；兼容 macOS/Linux 旧密钥身份。探测受阻时保留原数据，不建立替代密钥。跨平台身份测试使用夹具，不代表已在 macOS/Linux 真机验证。
3. **误用上游自动更新的风险。** 开发版和没有独立更新服务的安装版明确显示更新不可用；即使旧安装残留 `app-update.yml`，也不会仅凭该文件启用上游更新。EconoMind 当前没有可用的独立自动更新服务。
4. **文献库工具栏错误换行。** 修正搜索框在桌面宽度下占满整行的问题，保留窄屏自适应布局；文献库渲染测试 339 项通过。
5. **连接器说明超出文档预算。** 精简重复说明，保留输入参数、返回结构和执行实现，相关 71 项通过、4 项按原条件跳过。
6. **升级后测试夹具失效。** 修正已删除远程/市场模块的测试清单、中文默认语言的定位、Windows 测试运行时注入和测试 PowerShell 的进程级策略；未更改系统执行策略。

桌面测试使用临时资料库及本地模型响应服务。真实 Python 执行通过不等于自动下载/安装所有运行环境成功。开发资源中的 micromamba / Windows bundled runtime 未完整随此次构建准备，相关自动配置和所有语言执行不能据此宣称完成验证。付费模型、外部数据源、SSH/集群和可选模型下载未作全面联网验证。

测试可以验证保存、请求、解析、交互和错误处理是否符合预期，**不能保证模型生成的研究判断、筛选结论或论文观点百分之百准确**。研究结果仍需对照原文及方法检查。
