# EconoMind CLI/SDK 包说明

本仓库保留 `packages/open-science/` 及 `@aipoch/open-science` 包标识，以维持继承的 CLI、SDK 与 Electron 打包路径兼容。

这是上游包的兼容副本，不代表 EconoMind 已发布了相同名称的 npm 包，也不代表本仓库拥有上游 npm scope 的发布权限。源码内部使用方式以该目录的 `package.json`、CLI 实现和测试为准。

如需独立发布 EconoMind 的 CLI/SDK，必须先适配包名、命令、仓库元数据和发布工作流，再单独验证可安装的包产物。本仓库的 GitHub Actions 当前关闭，本次整理没有进行 npm 发布。

来源与许可见 [UPSTREAM.md](../UPSTREAM.md)。
