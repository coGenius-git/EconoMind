# EconoMind · Atelier de recherche en économie et gestion

EconoMind accompagne la recherche en économie, gestion, finance, comptabilité et politiques publiques. Son interface Web locale nécessite le backend de l’application.

Ce dépôt adapte AIPOCH Open Science. Le code source porte la version 0.34.1 ; un installateur personnalisé distinct utilise l’étiquette 3.0.0. Les publications et les références DOI du projet d’origine ne sont pas celles de ce dépôt.

## Documentation et démarrage

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)
- [Docs](../README.md)
- [Startup](../DEPLOY.md)

`Node.js 24` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

Au premier démarrage, choisissez le stockage et configurez un modèle.
