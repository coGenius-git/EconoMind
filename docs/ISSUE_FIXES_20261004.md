## 2026-10-05 追加：工作台页面切换

首页进入文献库或研究工作区时，原先才开始加载页面模块，且顶层 `Suspense` 使用空占位。修复后，在首页绘制完成后的空闲时间逐个预加载模块，鼠标移入或键盘聚焦导航入口也会提前加载；导航与实际页面共用导入结果。加载尚未结束时保留顶部导航及“加载中…”提示，可立即返回首页或选择另一模块。预加载只加载代码，不挂载隐藏页面，不启动其数据请求。

文献库的文献计量图表和筛选向导改为打开工具时才加载，减少普通列表导航的依赖。此前的新手指南撤回、设置独立窗口及预览收起功能均保留。

已有会话返回研究工作区时，还会因页面重新挂载而重复渲染整段会话。现在保留一个已访问工作区的 DOM 和状态，切走时通过 React 的 `Activity` 清理页面效果和订阅，返回时恢复；首页清空导航项目选择时仍保留该界面的项目范围，打开另一项目时更新范围。首次访问前不挂载工作区。隐藏界面的对话框不会参与全局快捷键或关闭命令的阻挡判断。文献库沿用重新进入时的读取流程，避免隐藏期间的数据变化遗漏。`Activity` 的行为参见 [React 官方文档](https://react.dev/reference/react/Activity)。
