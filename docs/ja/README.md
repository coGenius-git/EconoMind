# EconoMind · 経済・経営研究ワークスペース

EconoMind は経済学、経営学、金融、会計、公共政策の研究を支援するデスクトップアプリです。ローカル Web モードにもアプリのバックエンドが必要です。

このリポジトリは AIPOCH Open Science を基にカスタマイズされています。ソースのバージョンは 0.34.1、別のカスタムインストーラーのラベルは 3.0.0 です。上流プロジェクトのリリースや DOI は、このリポジトリの成果ではありません。

## ドキュメントと起動

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)
- [Docs](../README.md)
- [Startup](../DEPLOY.md)

`Node.js 24` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

初回起動時にデータの保存先とモデルを設定してください。
