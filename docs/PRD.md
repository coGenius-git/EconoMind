# EconoMind 产品需求与验收范围

EconoMind 面向经管研究，将已有研究工作台能力用于文献、研究设计与数据分析辅助。底层运行框架大量继承 Open Science，来源见 [UPSTREAM.md](../UPSTREAM.md)。本文件描述项目方向和验收要求，不将计划内容标记为已实现。

## 用户与研究流程

目标用户为经济学、管理学、金融学、会计学与公共政策研究者。典型流程为：确定问题 → 获取及筛选文献 → 设计研究 → 分析数据 → 核验并整理输出。

## 核心要求

| 模块       | 要求                           | 验收关注点                             |
| ---------- | ------------------------------ | -------------------------------------- |
| 项目工作区 | 组织会话、文献、输入与输出     | 重启后记录可读取，项目之间保持边界     |
| 文献流程   | 检索、导入、去重、筛选与导出   | 来源可追溯，失败可定位，评分与条件一致 |
| 研究设计   | 提供框架、变量、假设与方法建议 | 建议符合研究问题，说明适用条件及限制   |
| 数据分析   | 保存输入、代码、执行结果与图表 | 口径清楚，执行证据可检查，结果可复现   |
| 专家示例   | 可直接实践的经管任务           | 输入、步骤、预期输出和核验方法齐全     |
| 本地存储   | 管理项目记录和模型凭据         | 存储位置明确，迁移及备份可验证         |

## 当前状态的表达

当前源码提供上述方向的功能与框架，不能仅凭文件存在宣称全部验收通过。已确认的 Windows 源码启动基础与未覆盖限制见 [README](../README.md#项目状态)；迭代优先级见 [路线图](../ROADMAP.md)。

## 产品边界

模型输出是研究辅助结果。文献真实性、引用、数据授权、方法条件和结论需要核验。桌面与本地 Web 模式共享后端，完整 Web 功能不能由静态页面独立提供。
