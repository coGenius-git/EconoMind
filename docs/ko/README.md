# EconoMind · 경제·경영 연구 작업 공간

EconoMind는 경제학, 경영학, 금융, 회계 및 공공정책 연구를 지원하는 데스크톱 앱입니다. 로컬 웹 모드에도 앱의 백엔드가 필요합니다.

이 저장소는 AIPOCH Open Science를 기반으로 수정되었습니다. 소스 버전은 0.27.2이며 별도의 맞춤 설치 프로그램은 3.0.0을 사용합니다. 원본 프로젝트의 릴리스와 DOI는 이 저장소의 배포 성과가 아닙니다.

## 문서 및 실행

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)

`Node.js 22` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

처음 실행할 때 데이터 위치와 모델을 설정하세요.
