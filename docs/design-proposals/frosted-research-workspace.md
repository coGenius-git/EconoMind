# EconoMind 雾白研究室：D 方向设计方案

日期：2026-10-05  
状态：D 方向正在进行第二轮本地实现，待本轮复验和用户验收；尚未推送或合并到 GitHub。初版已完成部分功能检查，但视觉效果未被用户接受，初版“已与参考图检查”的记录不等于视觉验收通过。本文描述当前代码中的第二轮材质与布局，不代表本轮视觉、工作流或性能验证已经通过。当前规范见 [`docs/design.md`](../design.md)，语义配色与材质分别以 [`main.css`](../../src/renderer/src/assets/main.css) 和 [`research-workbench.css`](../../src/renderer/src/assets/research-workbench.css) 为准。

本地覆盖范围：研究首页、文献库及筛选流程、研究工作台、设置和文献计量面板。保留既有深色主题与业务操作；未新增专注模式按钮、自动阅读布局切换或新的业务能力。

## 1. 设计定位

以用户选定的 D「雾白玻璃」为视觉母版：低饱和蓝银灰折光背景、紧凑的悬浮胶囊导航、彼此独立的磨砂玻璃面板，以及承载正文的局部浅色纸面。布局容器本身透明，面板之间留出能看见背景的间隙，形成有空间层次的现代学术研究环境。

学术感来自内容组织、正文排版、文献索引与严谨的图表，不依赖装饰性名言、校徽或复古元素。玻璃表现界面的空间关系，正文承载研究内容。

保留 D 的通透感、细亮边、冷灰投影、斜向折光与悬浮工具，去掉四周口号与装饰引语。新背景素材只含抽象玻璃薄片和明暗，不含 UI 或文字；导航、控件和正文由真实界面渲染。概念图中的研究内容、文献、日期和状态均为视觉占位，实施时由现有真实数据提供。

### 三层材质

1. **背景层**：使用生成的 `research-glass-atmosphere.webp`，居中覆盖页面，叠加 35% 浅蓝灰雾层。保留可见的冷灰阴影、透明薄片与斜向折光，不使用动态流光。素材来源、提示词和压缩信息见 [glass-background-source.md](glass-background-source.md)。
2. **玻璃层**：通用玻璃从 32% 白色渐变到 18% 浅蓝色，使用 18px 模糊、`saturate(0.78) brightness(1.08)`、1px 白色亮边与冷灰分层投影；首页和文献侧栏采用稍密的 40%–28% 浅色。导航、侧栏和主内容面板分别拥有玻璃材质，外部布局容器无填色、边框、投影或模糊。输入框外框采用 32%–20% 浅色，内输入区为 74% 浅色底。
3. **阅读层**：AI 长回答放在局部 88% 浅色纸面上，正文周围的对话滚动区保持透明，不再整片铺白。首页列表和设置/研究工具正文同样使用局部纸面；密集数据表、文件预览与 PDF 页面保留不透明阅读面或阅读器原始背景。阅读纸面不增加模糊，也不叠加装饰高光。

每个主要玻璃面板只过滤一次背景，布局外壳不做模糊，局部纸面和输入框不叠加新的模糊层。无模糊支持或减少透明度偏好下，使用不透明的 `--research-overlay` 浅色底替代。移动端工作台抽屉与设置/工具外壳关闭模糊，避免影响固定抽屉定位；强制色彩模式移除背景图片和投影，使用系统画布与边界色。

### 形状与字体

- 布局容器透明且无圆角；首页/文献独立玻璃面板为 24px，对话和设置/工具面板为 26px，工作台侧栏为 22px，局部纸面为 14px，预览面板为 20px，输入框外框/内区为 28px/18px。共享基础圆角为 10px，按钮和菜单继续由既有组件控制；顶部导航在宽屏为胶囊，窄屏为 24px 圆角框。不要用冲突的 utility 覆盖具名材质规则。
- 大空间间距采用 16/24/32px，列表行内采用 8/12px；不把所有信息包成独立卡片。
- 品牌、少量页面标题和 AI 回答纸面中的标题使用衬线字体，中文标题可使用宋体风格；正文、导航、表格和按钮使用系统无衬线字体；代码保持等宽字体。
- 共享导航品牌为 22px 衬线体，首页主标题为 30px 衬线体。AI 回答正文为 16px、1.8 行高，一级/二级/三级标题为 28px/26px/20px；768px 以下正文为 15px、1.75 行高，标题为 24px/22px/18px。代码为 13px、1.6 行高，工具控件与元信息保留紧凑密度；不全局放大所有阅读器。现有界面缩放能力继续有效。
- 优先使用项目已有或系统字体；若以后打包字体，单独确认字体许可与体积。

## 3. 整体布局

应用标题栏保留系统窗口操作区，悬浮导航位于其下，不覆盖 Windows 最小化、最大化、关闭按钮及拖拽区域。

宽屏时顶部导航为居中的玻璃胶囊，包含 EconoMind、研究首页、文献库、研究工作台和设置，并由页面提供附加操作；搜索沿用既有入口与快捷键。保留现有三个模块的语义与导航入口；项目选择放在工作台内部。

共享导航最大宽度 740px，最小高度 62px，默认顶部留白 20px、底部 24px。布局外壳不设内边距，默认左右及底部外边距 28px；1440px 及以上左右为 36px、底部 30px，1100px 以下为 16px，768px 以下左右为 10px、底部 12px。首页和文献库独立面板间距为 18px，1100px 以下为 12px；工作台侧栏和右预览在分隔条两侧各预留 16px，展示未被过滤的背景。

侧栏与主内容是各自独立的玻璃面板，承担项目、对话或文献集合导航，并沿用各页面现有收起能力与断点。长项目名截断并可查看全名，主内容支持滚动，分栏支持拖动调整。

输入框在所属对话栏底部保留布局空间，视觉上悬浮但不遮挡最后一条消息。引用、状态与辅助面板也通过真实分栏布局承载，避免生成图中的任意叠压。

## 4. 各页面的表达

### 研究首页

- 顶部是克制的标题、项目搜索与“新建项目”按钮。
- 概览标题区在玻璃主面板内保持透明；项目列表与最近对话双栏各自使用 88% 阅读纸面，24px 内边距（768px 以下为 16px）、14px 圆角。列表呈现标题、学科和现有活动信息，以细线与留白组织，内部不再套一层卡片。
- “需要你处理”的状态优先显示，有真实状态时才出现；正常空闲时保持干净。
- 学科分类使用文字、细线或小标记，减少现有多种彩色圆点带来的杂色。
- 项目、成果和对话数量沿用实际数据，不增加没有业务来源的统计卡片。

### 文献库

- 左侧玻璃栏容纳文献集合与筛选，中间独立玻璃面板内的实底区域承载文献列表，右侧为可收起的详情或预览。
- 列表使用整齐的作者、年份、标题和期刊排版；选中态为蓝灰浅底加清晰边线。短窗口下文献目录区域可纵向滚动，结果表保留至少 16rem 高度与自身滚动区，避免标题和筛选控件挤没结果。
- PDF 页面保持原始显示色彩与比例，外围阅读区使用不透明底；保留原有阅读器工具栏，不对每一层工具栏叠加模糊。
- 引用跳转和定位高亮短暂、明确，不持续闪烁。

### 研究工作台

- 延续现有对话与文件/成果预览能力，默认布局按当前使用场景调整，不强制改为论文编辑器。
- 对话为中心时：可收起的项目/会话导航、主对话区、可打开的文件或成果预览区。
- 阅读为中心时：通过现有分栏拖动、收起与预览能力扩大 PDF/成果区域。本轮未新增一键切换阅读重心或专注模式按钮。
- 侧栏与对话各自使用玻璃面板；对话滚动区透明，AI 回答通过 88% 局部纸面、衬线标题与更宽松行距组织阅读。输入框外框半透明、内输入区使用较高不透明度的浅底；代码、公式、表格和预览保持各自清晰的内容表面。
- 运行、等待输入、审批和完成状态沿用既有业务判断，只改变视觉表达。

### 设置、对话框和菜单

- 设置沿用现有分类与搜索，桌面使用玻璃外壳与内嵌 88% 纸面，纸面外边距 10px、圆角 18px；移动端外壳使用实底，纸面外边距 4px、圆角 14px。
- 设置和文献计量外壳使用玻璃；其余对话框、菜单和浮层继续使用既有高不透明度表面，不在每个浮层上追加模糊。
- 主按钮为墨蓝灰实心，次按钮为浅色描边，危险操作仍使用危险色；禁用态不可与可操作状态混淆。
- 空状态使用一句说明和一个直接操作；错误提示沿用项目现有 ErrorNotice 能力。

## 5. 动效与响应式

- 悬停和选中态过渡约 120–160ms；面板展开、收起约 180–220ms。主要使用透明度与小幅位移，不做持续漂浮、视差或弹跳。
- 尊重减少动态效果偏好，关闭位移和非必要过渡。
- 材质外壳使用 1440px、1100px、768px 断点调整边距与圆角。具体侧栏、列表和预览仍沿用组件自身断点与既有收起逻辑，不强制所有页面在同一宽度采用同一栏数；须继续以真实内容和缩放检查。
- 窄窗口时顶部胶囊变为紧凑圆角框，模块导航移至第二行的三等分网格，图标在上、12px 文字在下并允许换行；宽屏继续使用横向导航。
- 保留现有原生全屏、分栏拖动和收起能力；原提案中的独立全屏专注入口与专注专用边距方案未纳入本轮实现。

## 6. 实施路径

1. **第二轮已接入代码：统一视觉基础。** 浅色语义 token 保持雾灰/蓝灰；独立材质样式改为生成背景加浅雾、低不透明度玻璃面板、局部阅读纸面与响应式降级，继续复用 shadcn/Radix。
2. **已本地实现：主要页面。** 首页、文献库及筛选流程、研究工作台、设置和文献计量面板已接入语义化 surface hooks；共享控件随全局 token 更新。
3. **已同步规范，待本轮复验。** `docs/design.md` 描述当前第二轮本地代码、保留的交互契约与本轮未包含的专注模式功能；具体视觉和回归结果由本轮实际检查补充。
4. **待完成：用户验收与后续发布。** 初版的功能检查不能替代本轮复验或视觉验收。代表工作流、视觉、缩放和性能结果需要分层记录；用户测评并确认后再正式推送、合并 GitHub。

本轮实现聚焦浅色主题 D。既有深色语义配色保留，新增材质角色映射到原深色背景、阅读面、边框与投影，并关闭生成背景图与模糊；玻璃填色映射为深色背景之间的低差异渐变。共享布局变化仍需要深色回归验收，不自动替换成用户未选择的 E 方向。

## 7. 验收条件

- 同时具备 D 的冷灰折光背景、紧凑悬浮导航、独立玻璃面板与局部阅读纸面；面板间必须能看见背景层次，不能重新变成整片浅白矩形。
- 首页、文献库与研究工作台使用一致的色彩、圆角、边界与焦点样式。
- 局部纸面的背景明暗不影响正文辨识，反光、悬浮输入框和辅助面板不遮挡正文；长列表、长标题和空状态布局成立。
- 常规正文目标对比度至少 4.5:1；大文字和关键非文本控件目标至少 3:1。对半透明区域测量实际合成后的颜色组合。
- 搜索、切换项目、发送消息、查看文献和成果、调整分栏与设置等现有核心操作可用，键盘焦点清楚可见。
- 检查 100%、125%、150% 界面缩放及窄窗口；保持 Windows 标题栏安全区和滚动区域正常。
- 在代表性长对话和 PDF 页面中比较滚动、分栏拖动的流畅度；若模糊导致明显回退，降低或关闭背景模糊，不以牺牲操作响应换取效果。
