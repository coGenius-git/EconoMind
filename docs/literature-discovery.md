# 文献检索与初筛

本文档说明文献检索功能的范围、环境要求、使用步骤与已知限制。功能入口在软件内的**文献库 → 检索外部数据库**，打开 **检索 OpenAlex** 窗口。当前窗口只提供 OpenAlex；知网浏览器、题录解析和初筛代码保留用于已有数据与内部接口兼容，不再作为此窗口的操作入口。

## 1. 功能范围

| 能力                                            | 数据来源             | 自动化程度                                                            |
| ----------------------------------------------- | -------------------- | --------------------------------------------------------------------- |
| 检索词、年份、文献类型、语言、被引下限筛选      | OpenAlex（官方 API） | 自动；保留有全文地址的记录，实际可下载性在导入时验证                  |
| 开放获取、DOAJ 筛选；相关度、最新、被引次数排序 | OpenAlex（官方 API） | 自动；不提供无法在 OpenAlex 验证的 CSSCI、SCI 等来源级别              |
| 勾选记录后导入文献库                            | OpenAlex             | 自动；重复条目策略可选，同时尝试下载 PDF                              |
| 导入完成后返回文献库                            | —                    | 自动关闭窗口，显示题录与 PDF 下载数量；失败或未保存任何条目时留在窗口 |

单次检索上限 200 条。文献类型使用 OpenAlex 原生类型：期刊论文、综述、学位论文、会议论文、书籍、书籍章节、预印本、数据集、报告与其他。语言可选全部、英文或中文。

## 2. 环境要求

OpenAlex 检索通过官方 API 完成，无需登录知网或启动额外浏览器。源码启动依赖见 [README 第 1 节](../README.md)。下面的浏览器要求仅适用于保留的知网内部接口。

| 项            | 要求                                                 | 说明                                                                    |
| ------------- | ---------------------------------------------------- | ----------------------------------------------------------------------- |
| 浏览器        | Microsoft Edge（Windows 10/11 自带）或 Google Chrome | 按 Edge → Chrome 的顺序尝试；两者都缺失时才回退到 Playwright 自带浏览器 |
| Playwright 库 | 随 `npm ci` 安装                                     | 仅提供驱动能力，不是浏览器本体                                          |

只有在系统既没有 Edge 也没有 Chrome 的机器上，才需要下载兜底浏览器：

`playwright` 在 `package.json` 中属于运行时依赖而非开发依赖，因为它是本功能的组成部分；`@playwright/test` 仍为开发依赖。

## 3. 首次使用

1. `npm ci`。
2. `npm run dev:isolated`，等待 **EconoMind (DEV)** 窗口。
3. 打开**文献库**，左侧「研究工具」中选择**检索外部数据库**。
4. 如需个人 API 额度，在窗口配置 OpenAlex Key；已有 Key 会显示已配置，不需要再次输入。
5. 填写检索词与条件，点**搜索**。支持英文检索词与 AND、OR、NOT；关键词会匹配标题、摘要或全文。
6. 在候选列表勾选需要的记录 → 选择重复条目策略 → **导入所选条目**。
7. 等待题录保存与 PDF 获取完成，窗口自动关闭并返回文献库，顶部显示导入数量及 PDF 结果。题录保存成功但 PDF 未下载时仍返回文献库，可在文献详情中继续查找全文。导入失败或未保存任何条目时，窗口保留检索词与勾选项。

## 4. 保留的知网内部接口

本节记录旧接口行为，当前 OpenAlex 窗口不提供知网登录、检索或题录文件导入控件。

- 知网没有可用的公开检索 API，本功能通过独立的 Chromium 访问其检索页并读取结果列表。
- 浏览器使用持久化配置（profile），位置在数据目录下的 `literature/cnki-browser-profile`。`dev:isolated` 模式下为仓库内的 `.dev-isolate/`；该目录已被忽略，不会提交。
- 每位使用者各自登录，profile 不共享，登录状态互不影响。
- 知网可能在首次访问、会话失效或触发风控时要求安全验证。需在可见窗口内人工完成，完成后会话写入 profile；站点仍可能要求再次验证。验证窗口不会因为 30 秒内未完成而自动关闭，登录操作最长等待 10 分钟。
- 公开题录检索不再要求先通过登录状态检查。遇到验证会保留窗口；验证完成后重新检索即可。网络、代理或证书错误会提示连接不可用，结果结构变化会提示题录文件备用导入。
- 检索时窗口会显示在屏幕上（位置 120,120）。这是有意为之：一旦知网要求验证，可见窗口才便于处理。

提示对照：

| 提示             | 含义               | 处理                                     |
| ---------------- | ------------------ | ---------------------------------------- |
| 知网会话已就绪   | 会话可用           | 直接检索                                 |
| 需要完成安全验证 | 知网要求滑块验证   | 点登录知网，在窗口内完成验证后关闭标签页 |
| 结果结构未识别   | 站点页面结构变化   | 需要更新选择器，见第 6 节                |
| 未登录知网       | 未检测到可用会话   | 可先检索公开题录，按站点提示验证或登录   |
| 知网连接不可用   | 网络或代理连接失败 | 检查网络、代理和浏览器错误后重试         |

## 5. 全文获取

| 途径                 | 覆盖范围                             | 操作位置                         | 方式                                  |
| -------------------- | ------------------------------------ | -------------------------------- | ------------------------------------- |
| 开放获取全文         | PMC、Europe PMC、Unpaywall           | 文献库中的文献详情页「查找全文」 | 自动查找、下载并归档                  |
| OpenAlex PDF         | 出版社、开放仓储及 OpenAlex 内容服务 | 检索面板「导入所选条目」         | 自动下载所选记录的 PDF 并归档         |
| 知网全文（内部接口） | 机构 IP 或已授权个人会话             | 保留的导入接口                   | 点击官方 PDF 下载入口、验证文件并归档 |

OpenAlex 导入先保存题录，再以最多 3 个并发任务下载所选记录的 PDF。优先尝试直接 PDF 地址及其他开放版本，仓储介绍页会读取明确的 PDF 链接；没有可用版本或下载失败时保留题录，并在关闭窗口后于文献库显示未下载数量。可在详情中继续查找全文，或重新检索并导入相同记录重试；已有全文 PDF 不会重复下载。保存前检查 PDF 格式、大小和页数，并记录校验值。

出版社和仓储的开放 PDF 无需 OpenAlex API Key；OpenAlex 自身缓存的 `content_urls.pdf` 则需要在连接器设置中配置 Key，受服务配额约束。Key 仅在请求内容服务时添加，不写入文献题录或附件来源记录。参见 [OpenAlex 官方全文文档](https://help.openalex.org/access/fulltext/)。

OpenAlex 的 429 分为短时请求频率限制与日额度耗尽。短时限制遵守 `Retry-After`，最多自动重试两次；日额度耗尽立即停止请求，按响应标头显示恢复时间。同一条件的成功检索缓存 5 分钟，日额度冷却在不同查询间共享。未配置 Key 的请求使用出口 IP 的共享额度，代理出口尤其容易耗尽；可在检索面板点**配置 OpenAlex**，获取并保存免费个人 Key，保存后自动继续当前查询。更换 Key 后不会沿用旧额度的冷却。参见 [OpenAlex 官方认证与配额说明](https://help.openalex.org/api/authentication/)。

知网导入沿用检索所用的持久浏览器 profile 和当前网络，逐条点击官方 **PDF下载** 入口；跳到登录页时尝试站点的 **IP登录**。实际授权仍由知网识别机构 IP 或当前账号。浏览器下载事件返回的文件通过大小、PDF 格式、页数与校验值验证后，保存为文献库全文附件。登录或安全验证未完成时保留窗口和题录，面板显示具体原因；完成后重新导入对应记录即可重试，已有全文不会重复下载。仅有 CAJ、下载到 HTML 或超限文件时不会作为 PDF 归档。会话凭据不导出到应用配置或附件记录。

需要大批量全文时，建议通过图书馆文献传递/馆际互借、联系作者索取，或优先采用开放获取版本。

## 6. 已知限制

| 限制           | 说明                                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| 知网页面选择器 | 集中在 `src/main/literature/discovery/cnki-browser.ts`（结果列表选择器、等待选择器），站点改版后需同步调整           |
| 知网记录无摘要 | 抓取结果只包含标题与题录信息，初筛依据标题与元数据                                                                   |
| 知网抓取页数   | 最多 12 页，可通过同文件中的页数上限调整                                                                             |
| 初筛依据       | 仅标题与摘要；结论为建议，可在获得全文后复核                                                                         |
| 知网条件筛选   | 年份与文献类型在候选元数据上筛选；无法可靠核实期刊级别及被引下限时，会明确提示条件未应用，不把关键词推断当作期刊认证 |
| 大题录文件     | 最多解析 1000 条题录；每批导入最多选择 200 条，重复条目继续复用文献库已有记录                                        |
| 验证码         | 滑块验证无法自动完成，需要人工介入一次                                                                               |
