本次在 `陈卓名新功能添加和布局修改` 分支，以 EconoMind `9ffefac` 为起点，适配 AIPOCH Open Science main 的固定提交 `c87a5668d6d53d2752ffb46b9f36a307cfca8cb1`。源码版本为 `0.34.1`。本次是本地源码适配，不代表已提交、推送或发布安装包。

## 新增能力与入口

| 能力                      | 入口与使用方式                                             |
| ------------------------- | ---------------------------------------------------------- |
| 智能收藏                  | 文献库 → 新建收藏 → 智能收藏；配置纳入、排除规则和分类模型 |
| PDF 图、表与算法提取      | PDF 阅读器中的图表视图；支持文献附件和工作区 PDF           |
| PDF 批注、Notebook 与导出 | PDF 阅读器的批注工具、笔记视图及导出操作                   |
| 书签                      | 文本、PDF 与会话中的书签操作；按来源定位                   |
| 期刊数据集                | 文献库 → 期刊；导入数据集并与文献匹配                      |
| 全局搜索                  | 搜索按钮或 Ctrl+K；覆盖项目、会话、消息、文件和文献        |
| `.science` 研究包         | 会话菜单导出；项目菜单导入；支持拖入和文件关联             |
| 研究回放与讨论            | 普通会话与导入研究包的回放、讨论入口                       |
| 完整会话分叉              | 会话菜单 → 分叉；保留来源并在独立分支继续研究              |
| 可复现检查与 RO-Crate     | 成果文件与会话的复现检查、结果比较、导出操作               |
| 多侧聊                    | 工作区的侧聊入口；由新版会话调度管理                       |
| 设置分组、搜索和资源权限  | 设置页及其搜索；保留 EconoMind 的经管专家配置              |
| 更新的模型与服务配置      | 模型选择器、提供方配置及能力识别；包含上游的新模型目录     |
| 新版数据连接器            | 设置 → 连接器；保留文献图谱、Zenodo 与 Grants.gov          |
| Office 阅读器             | Word、Excel、PowerPoint 的分页、搜索及预览控制             |
| WSL2 支持                 | Windows 执行环境与 WSL 设置引导；不自动替用户安装 WSL      |
| 故障诊断与恢复            | 会话诊断导出、启动和存储恢复、后台任务生命周期管理         |

外部模型、连接器等功能需要用户自己的服务配置。自动化验证使用模拟智能体与隔离数据目录，不调用用户的付费模型，也不代表所有外部服务均已完成实网验证。

## 保留的 EconoMind 定制

- 文献库保持独立完整页面，从顶部工作台导航进入；工作区与子智能体的文献引用也路由到该页面。没有将主入口改成右侧紧凑文献库。
- 经管五阶段文献筛选，包括条件组合、概念/关系/观点整理、证据定位和报告导出。
- 文献计量图表和相关经管技能。
- 研究领域分类、经管项目模板、研究设计与计量分析技能、四个经管专家。
- EconoMind 的品牌名称和本仓库入口；新图标替换状态见下文。

## 文献筛选模型返回格式修复

- 从实际 Zod 校验规则生成 JSON Schema 随请求发送，明确字段类型、枚举及长度限制；移除容易被原样复制的竖线枚举示例。校验失败时反馈具体字段路径和错误类别，只对失败片段重试一次。
- 接受说明文字或 Markdown 代码块包裹的单个完整 JSON；保留引文原文，拒绝多个含糊结果、截断片段和损坏 JSON。模型返回层兼容数字页码字符串、缺失/空值的可选元数据及额外辅助字段，持久化数据继续严格校验。
- 最终格式错误记录经过限制的校验信息，便于诊断；不记录原始模型回复或论文全文。人工决定及原文证据匹配规则不变。
- 修复前新增回归用例复现 3 项失败，修复后 65 项相关测试通过；主进程类型检查、ESLint、格式检查与桌面构建通过。
