# EconoMind · 经管智研工作台

EconoMind 是面向经济学、管理学、金融学、会计学与公共政策研究的 AI 辅助研究桌面软件，也提供依赖本机后端的 Web 模式。

本仓库基于 AIPOCH 的 Open Science 源码进行定制。源码版本为 0.34.1，定制安装包另使用 3.0.0 标签。上游发布、DOI 和下载链接不代表本仓库的发布成果。

## 文档与运行

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)
- [Docs](../README.md)
- [Startup](../DEPLOY.md)

`Node.js 24` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

首次启动时按向导选择数据位置和模型。
