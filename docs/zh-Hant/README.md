# EconoMind · 經管研究工作台

EconoMind 是協助經濟學、管理學、金融學、會計學與公共政策研究的 AI 桌面軟體，亦提供需要本機後端的網頁模式。

此儲存庫以 AIPOCH 的 Open Science 原始碼為基礎進行客製化。原始碼版本是 0.34.1，客製安裝程式另採 3.0.0 標籤；上游版本、DOI 與下載資訊不代表此專案的發行成果。

## 文件與執行

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)

- [Startup](../DEPLOY.md)

`Node.js 24` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

首次啟動時，請依設定精靈選擇資料位置與模型。
