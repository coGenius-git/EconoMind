# EconoMind · Рабочая среда исследований экономики и управления

EconoMind помогает в исследованиях экономики, управления, финансов, бухгалтерского учёта и государственной политики. Локальный веб-интерфейс требует работающего серверного компонента приложения.

Этот репозиторий адаптирует AIPOCH Open Science. Версия исходного кода — 0.34.1; отдельный изменённый установщик использует обозначение 3.0.0. Релизы и записи DOI исходного проекта не являются релизами этого репозитория.

## Документация и запуск

- [EconoMind](https://github.com/coGenius-git/EconoMind)
- [README](../../README.md)
- [Docs](../README.md)
- [Startup](../DEPLOY.md)

`Node.js 24` + `npm`:

```bash
git clone https://github.com/coGenius-git/EconoMind.git
cd EconoMind
npm ci
npm run dev
```

При первом запуске выберите место хранения данных и настройте модель.
